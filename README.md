# Site d’Octo (GitHub Pages)

Pages publiques d’Octo, servies sur https://prunob.github.io/octo/ (dépôt public `prunob/octo`, branche `main`, racine).

- `index.html`, `support.html`, `privacy.html` : anglais (langue source de l’app).
- `fr/index.html`, `fr/assistance.html`, `fr/confidentialite.html` : français.
- `images/` : icône, mascotte, captures 6,3" réduites (978 px de haut).
- `app-ads.txt` : même ligne que Palier (même compte AdMob). AdMob le cherche à la racine du domaine du site déclaré dans la fiche App Store : il est déjà servi par Palier sur https://prunob.github.io/app-ads.txt si le site déclaré est `prunob.github.io`.

URL à mettre dans App Store Connect :
- Assistance : https://prunob.github.io/octo/support.html (fr : https://prunob.github.io/octo/fr/assistance.html)
- Confidentialité : https://prunob.github.io/octo/privacy.html (fr : https://prunob.github.io/octo/fr/confidentialite.html)
- Marketing : https://prunob.github.io/octo/ (fr : https://prunob.github.io/octo/fr/)

Mise à jour : remplacer les fichiers dans le dépôt GitHub (interface web, « Add file › Upload files »).
Le bouton « Bientôt sur l’App Store » est à remplacer par le lien de l’app quand elle sera publiée.
